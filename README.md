# CLAIM ZERO

**Discover it before the world does.**

Public alpha for testing a simple market mechanism:

- contributors submit verifiable discoveries for free;
- claims are timestamped and challengeable;
- buyers can define discovery hunts with objective acceptance criteria;
- paid pilots, when introduced, are agreed separately and transparently;
- no pay-to-claim, no ownership fiction, no fabricated revenue or traction.

## Alpha links

- Website source: `index.html`
- Submit a discovery: GitHub issue template `discovery.yml`
- Fund a hunt: GitHub issue template `fund-a-hunt.yml`
- Operating policy: `POLICY.md`

## Core rule

> First proven, not first shouted.

A vague tip does not reserve a discovery. Priority attaches only to a complete, independently assessable contribution with lawful evidence.

## Status

Launched as a public alpha on 20 September 2026. The immediate commercial objective is to validate whether a real buyer will fund a clearly scoped discovery hunt. No revenue is claimed until money has actually been received.
